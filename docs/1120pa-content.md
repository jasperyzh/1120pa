## 3. FAQs & Workflows

### Visitors & Couriers
- Entry and Exit via Gate 1 only.
- Requirements: Driving License, IC, Resident Address (e.g., B2-XX-XX).
- Purpose tracking: Visit, Delivery, Pickup (managed via the official app).
- Parking Area designations.
- Code of Conduct.

### Visitor App Guide (Gprop / JaGaApp)
1. Download Gprop on Apple Store / Google Play.
2. Click 'Forgot Password', enter email.
3. Receive temporary password via email.
4. Login and change password securely in Profile settings.
5. Use "Add New Visitor" functionality.

## 5. Community Hub (Marketplace & Services)

### Events & Announcements
- Emergency Announcements (Water cuts).
- Standard Announcements (Office holidays, facility closures).
- Internal Events (e.g., Riicycle).
- External Events (Workshops for children, local carnivals).

### Marketplace (Buy/Sell/Giveaway)
*"No spam, no MLM pitches, just neighbors selling cakes, plants, or old furniture. Keep it kind."*
- User posts live for 14 days, then automatically expire and archive.
- Categories: Buy / Sell / Trade / Request / Giveaway.
- Contact via WhatsApp - no in-app messaging.

### 🛠 Local Services Directory (Solopreneurs & Technicians)

This is where the condo community helps each other. A "NextDoor" style local services board.

#### Categories

| Category | Examples |
|----------|----------|
| **Home Repair** | Plumbers, Electricians, Handymen, Painters |
| **AC Service** | Installation, Repair, Chemical Wash, Gas Top-up |
| **Automotive** | Mobile Car Wash, Basic Mechanics, Tire Repair |
| **Cleaning** | House Cleaning, Window Cleaning, Sofa Cleaning |
| **Tutors/Lessons** | Academic Tutors, Music Teachers, Fitness Coaches |
| **Home Food** | Home Bakers, Cooked Meals, Dietary Specialties |
| **Professional** | Web Dev, Design, Accounting, Photography |
| **Beauty** | Hairdresser, Nail Tech, Aesthetic Services |

#### Service Provider Profile
Each provider gets a profile card with:
- **Business Name** & Photo
- **Category** (one primary)
- **Description** of services offered
- **Contact:** WhatsApp button (direct link)
- **Pricing:** Optional hourly rate or "Call for quote"
- **Portfolio:** Up to 4 images of past work
- **Availability:** Toggle for "Available" / "Fully Booked"

#### Why This Works
- **Trust:** Residents know they're hiring a neighbor
- **Convenience:** Need a plumber? Check the directory first
- **Local Economy:** Keep money within the community
- **No Middleman:** Direct WhatsApp contact, no app fees

#### Rules & Moderation
- Must be a verified resident (future: require unit verification)
- No MLM or pyramid schemes
- Professional conduct expected
- Admin can remove listings that violate rules
